# Contributing to Agent-Swarm

Thank you for contributing! As we build this structural architecture, please adhere to the following guidelines:

## Design vs. Documentation
We draw a hard line between ideas and reality:
* **`design/`**: If you are brainstorming, mapping out new agent schemas, or drafting contracts, place your work in `design/plans/`. 
* **`docs/`**: If you are documenting code that has been definitively implemented in the `src/` directory, or providing final operational guides, place it in `docs/`.

## Validation Scripts
Always ensure your changes adhere to our structural rules by running the validation scripts located in the `scripts/` directory before opening a Pull Request.

## Changelog
Please ensure your contributions are noted in the `CHANGELOG.md` using our append-only process.
